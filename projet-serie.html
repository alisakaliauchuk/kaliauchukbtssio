Projet Série

Application Web PHP CSS PSQL

Description

Projet Série - est un site web qui permet à l'utilisateur de s'authentifier et de voir la liste des films disponibles. Ils vont contenir leur description complète de leur créateurs, des acteurs, d'un genre, etc... Et son chaque épisode contient son résumé aussi et sa possibilité de la lecture de l'épisode.

Outils utilisés

  • XMind / Modelio
  • VS Code

Tâches

Documentation technique : analyse prévisionnelle (MCD, Diagrammes)


Base de données : elle contient les informations sur des utilisateurs inscrits, des séries sur site, leurs saisons, épisodes, etc...

FROM serie s

ORDER BY s.annee DESC;
